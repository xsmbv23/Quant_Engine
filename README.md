# Quant_Engine

Layer 1 Intelligence Plane for XSMB Forensic / Fosennic architecture.

This repository is intentionally **empty of trading intelligence at foundation stage**.

## Authority

`Project_Brain_AI` is the governance and memory control plane.

`Quant_Engine` is the Layer 1 execution plane for future sensors, mechanisms, functions and algorithms.

The chat window is communication only and is never the source of truth.

## Room model

Every sensor/mechanism/function/algorithm is a separately governed room with:

- room identity and version;
- input/output contract;
- dependency declaration;
- allowed callers;
- allowed corridors;
- required capabilities;
- lineage and source hashes;
- verification evidence;
- fail-closed door state.

No intelligence room is considered globally open merely because its source code exists.

## Foundation rule

Layer 1 remains **LOCKED** until the Brain/Data foundation explicitly opens the governed staircase.

Promotion remains **DENY**.
