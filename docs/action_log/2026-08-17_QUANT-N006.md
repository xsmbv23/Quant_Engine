# QUANT-N006 — Real-Source Acquisition Status Boundary

## Decision

The repository contained a data-buffer readiness adapter but no identifiable active
collector implementation to connect without guessing. Therefore N006 does **not**
fabricate a collector entry point.

Instead, N006 formalizes the exact metadata/status boundary that real collectors
must report into.

## New boundary

`data_buffer/acquisition_status.py`

It accepts independent observations containing only:

- business date
- source id
- exact raw SHA-256
- provenance completeness
- optional parsed cardinality diagnostic

It emits compact acquisition state:

```text
UNVERIFIED
PARTIAL
READY
CONFLICT
DRIFT_DETECTED
```

## Forensic rules

```text
A == B hash       -> READY may be observed
A != B hash       -> CONFLICT -> never merge
old hash != new   -> DRIFT_DETECTED -> never silently replace
incomplete proof  -> PARTIAL
single source     -> PARTIAL (no quorum)
```

The boundary is observational only. It has:

```text
promotion authority = 0
admission authority  = 0
execution authority  = 0
truth authority      = 0
```

Readiness remains a dashboard/visibility mechanism, not a gate that can promote
canonical data. This preserves the frozen Brain semantics and the existing data
buffer boundary. The repository's current data-buffer contract already states that
partial acquisition may accumulate while canonical promotion requires explicit
admission. fileciteturn766file0L2-L2

## Important finding

No active collector implementation was present in the repository tree under
`data_buffer/`; only the readiness/status primitives were present. The correct
Forensic action is therefore to establish the boundary first, then connect future
collectors to it explicitly. No guessed wiring was added.

## Tests

Added `tests/test_acquisition_status.py` covering:

- matching independent sources
- source conflict
- incomplete provenance
- frozen-hash drift
- observational-only semantics

## Performance policy

The boundary consumes metadata records, not raw datasets. It is O(number of
observations) and bounded in memory. It does not materialize canonical history,
call Room 01, or perform network work.
