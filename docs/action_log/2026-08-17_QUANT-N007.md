# QUANT-N007 — First Real Byte Capture Surface

## Decision

The system is no longer waiting for a hypothetical/general collector. Room 01 now has one deliberately narrow real-source acquisition adapter:

```text
source_id = ketqua16.net
source_url = https://ketqua16.net/
```

The live public surface was independently verified before implementation. The page exposes Xổ số miền Bắc / Truyền Thống navigation and a public result surface; the page also contains advertising/navigation content. The collector does not click, execute, or interpret any advertising content. It captures the HTTP response bytes as an opaque forensic artifact. citeturn1view0

## Collector contract

`collectors/ketqua16_raw.py`

The collector performs only:

```text
explicit business_date
        ↓
HTTP GET
        ↓
bounded byte stream (<= 2 MiB)
        ↓
SHA-256 exact response bytes
        ↓
append-only raw artifact
        ↓
compact receipt
```

It deliberately does NOT:

- parse 27 numbers
- normalize HTML
- infer business date
- merge sources
- replace previous evidence
- execute page JavaScript
- interact with advertisements
- promote to canonical truth

## First execution mechanism

`.github/workflows/collector-ketqua16.yml` is the execution path. It runs outside the Render Free 512 MiB runtime, avoiding memory pressure on the Render service.

Schedule:

```text
30 12 * * * UTC = 19:30 Asia/Ho_Chi_Minh
```

It also runs once when the workflow/collector is first installed, then daily. Its own data commits are excluded from the workflow trigger paths to prevent a self-trigger loop.

## Persistence

Raw artifacts are written under:

```text
data_buffer/raw_artifacts/YYYY-MM-DD/
```

and a compact metadata-only acquisition log is appended to:

```text
data_buffer/acquisition_status.jsonl
```

The acquisition log has `OBSERVATION_ONLY` authority and cannot promote data to canonical truth.

## Forensic boundary

```text
REAL HTTP BYTES
      ↓
RAW HASH
      ↓
RAW ARTIFACT
      ↓
ACQUISITION_STATUS
      ↓
ROOM 01 ADMISSION
      ↓
CANONICAL DATA (future, one-way)
```

`BUFFER != ENGINE INPUT` remains invariant.

## Ads / hostile page content

Advertisements are treated as page content, not as navigation commands. This collector uses HTTP response bytes only; it does not run browser JavaScript, click ad links, follow DOM instructions, or allow page content to become execution authority.
