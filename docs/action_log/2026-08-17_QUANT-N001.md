# QUANT-N001 — Layer 1 Admission + Room 01 Forensic Hardening

## Decision

Layer 1 is admitted as a separate Quant Engine repository under the frozen Brain/Forensic foundation. The Brain foundation is not reopened.

## Security semantics inherited

Database access is one Forensic admission FSM, not multiple independent systems:

```text
DB_EXISTENCE -> DB_BINDING -> SECRET_RESOLUTION -> DB_TLS_ADMISSION -> NETWORK_ORIGIN_PROOF -> DB_ROUND_TRIP -> PROMOTION
```

PASS at a gate is only a prerequisite for the next gate. It is never inherited permission. First FAIL or UNKNOWN stops reachability to later gates. Later gates are UNREACHED.

Each Layer 1 room has a distinct corridor key and room key. Protected rooms may require an inner release/chime response. Directional edges must be explicit; no implicit cycles.

## Room 01 transport boundary

The Input Adapter is transport-only.

Implemented foundation behavior:

- raw-byte SHA-256 hashing in chunks;
- NDJSON streaming;
- strict source-order validation;
- future-record rejection when `as_of` is supplied;
- bounded deque window with maximum 30 records;
- fail-closed contract errors;
- no sorting, feature engineering, signal filtering, or normalization in the adapter.

## Room 01 v3 hardening

The current signal implementation now explicitly enforces:

```text
SCORE != DECISION
FEATURE_VALUE != FEATURE_MEANING != FEATURE_SCALE
SAME_INPUT -> SAME_OUTPUT -> SAME_ORDER
NO_IMPLICIT_EDGE
NO_HIDDEN_STATE_BETWEEN_RUNS
NO_GLOBAL_CACHE
EXECUTION_SIGNATURE_REQUIRED
FORENSIC_RECEIPT_REQUIRED
```

Feature semantics are immutable metadata and remain separate from normalization policy. Temporal features are extracted before recency selection.

Room 01 emits raw candidates/signals only. It emits neither probability nor BUY/SELL decisions.

## Forensic receipt

`room_receipt.py` provides compact hashes for:

```text
input_hash
feature_snapshot_hash
policy_hash
output_hash
execution_signature
```

The execution signature identifies room version, code hash, Python version, and declared dependency hash. No credentials are accepted or emitted.

## Executable contract
