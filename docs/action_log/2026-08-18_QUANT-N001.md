Implemented admission rules:

1. exact raw-file SHA-256 is streamed in bounded chunks;
2. NDJSON is streamed line-by-line;
3. explicit ISO calendar dates are required;
4. future records are hard-denied when `as_of` is supplied;
5. source order is preserved; sorting is forbidden;
6. duplicate/non-casual dates are denied;
7. schema drift is denied;
8. `source_id` is required;

10. `raw_sha256` must be a 64-character lowercase hex upstream artifact identity;
11. a maximum 30-day causal window is enforced;
12. maximum line size is 16 KiB;
13. no synthetic fill or silent repair;
14. adapter remains observation-only and cannot promote canonical truth.

## Important correction

The initial implementation attempt incorrectly tried to hash an NDJSON line containing its own `raw_sha256` field. That is self-referential and therefore invalid forensic design.

It was immediately replaced with the correct rule:

```text
exact raw artifact bytes
        ↓
SHA-256 at acquisition boundary
        ↓
immutable receipt
        ↓
Room 01 adapter receives expected hash
        ↓
declared hash == expected hash
```

No self-referential hash is accepted.
