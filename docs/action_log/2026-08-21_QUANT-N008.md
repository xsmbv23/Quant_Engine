# QUANT-N008 — Source-Specific Collector Contracts

## Purpose

Correct the prior failure mode where a generic collector/parser boundary could accidentally treat page chrome, advertising, navigation, or arbitrary numeric HTML as lottery truth.

## Sources

- `ketqua16.net` — primary target
- `xsmb.com.vn` — independent source

## Contract rule

Each source now has its own explicit contract:

- `contracts/source_ketqua16_v1.json`
- `contracts/source_xsmb_v1.json`

Both require:

```text
REAL HTTPS RESPONSE
        ↓
EXACT RAW BYTES
        ↓
RAW SHA-256 = BYTE IDENTITY ONLY
        ↓
OFFICIAL RESULT PANEL
        ↓
27-VALUE CANONICAL DOMAIN
        ↓
SEMANTIC SHA-256
```

Advertising is explicitly classified as `NON_TRUTH_CONTENT`.
Navigation and header/footer chrome are also `NON_TRUTH_CONTENT`.
Generic page-number regex is explicitly forbidden as a truth extractor.

An ambiguous or missing official result panel is DENY.
A missing/duplicate/out-of-domain value is DENY.

## Why this matters

The web page is a building containing many rooms: the result panel is the truth-bearing room; advertisements are not truth-bearing rooms. The collector must prove which room it extracted from before semantic admission.

This is deliberately separated from the raw-byte identity hash. Two pages may differ byte-for-byte because of advertisements while carrying the same official 27-value result. Therefore raw hash equality is not semantic quorum.

## Brain interaction

No Brain state is mutated.

No promotion is unlocked.

Room 02 remains locked.

The Brain remains the governance authority; Quant Engine remains the Layer 1 observation/calculation boundary.
