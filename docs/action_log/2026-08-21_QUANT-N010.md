## Evidence semantics

A green GitHub workflow proves only:

```text
repository verifier execution
```

It does **not** prove:

```text
external Render runtime truth
```

Therefore every valid receipt must contain:

```text
execution_status       = PASS
 evidence_kind          = REPOSITORY_VERIFIER_EXECUTION
 external_runtime_truth = NOT_PROVEN
 promotion              = DENY
 pass_inheritance       = false
 unknown_is_not_pass    = true
 layer                  = LAYER_1_ROOM_01
```

## Forensic gate rule

```text
PASS_LOCAL
   !=
PASS_EXTERNAL
   !=
PROMOTION
```

Each gate owns its own evidence. No state is promoted by inheritance.
