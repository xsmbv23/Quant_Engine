## OBSERVED BLOCKER
`data_buffer/acquisition_status.py` treated equality of raw SHA-256 values as cross-source agreement. This is semantically incorrect for independent web sources because their HTML/response bytes can legitimately differ while representing the same 27-number result. The previous logic also allowed repeated observations from one source to satisfy `len(day_rows) >= 2`.

This could cause either:
- false `CONFLICT` for two independently correct sources; or
- false `READY` from duplicate captures of one source.

Both are dangerous because they corrupt the admission boundary before any research calculation begins.

## SELECTED BLOCKER / WHY
Highest-value safe blocker: fix quorum semantics without touching canonical source truth, Brain authority, or promotion.
